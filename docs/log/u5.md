# U5 — "Ejercicios": D6 exercises, images + text

## Built
- `lib/content/schemas.ts`: `ExerciseSchema` (id, title, trimesters 1–3,
  durationMin, equipment, benefits, steps 1–4 with `{ text, imageSrc }`,
  avoidIf, stopSigns, source). `imageSrc` shares one regex shape for both a
  real filename and the literal `placeholder.webp`.
- `lib/seed/ejercicios.json` + `.ts`: 12 general prenatal-wellness exercises
  (caminar, inclinación pélvica, gato-vaca, sentadilla con apoyo, elevación
  lateral de pierna, tres estiramientos, respiración diafragmática, círculos
  de tobillo, elevación de talones, piso pélvico/Kegel — which hands off to
  the existing `/herramientas/kegel` tool rather than duplicating it). Every
  step's `imageSrc` is today's shared placeholder, so `publishedOnly()`
  (Z1's gate, reused as-is) hides all 12.
- `scripts/validate-content.mts`: registers `ejercicios.json`, plus a new
  check — any step whose `imageSrc` doesn't contain "placeholder" must exist
  on disk under `public/assets/ejercicios/`, or the build fails with the
  exact missing filename.
- `app/(app)/herramientas/ejercicios/page.tsx`: trimester filter (defaults to
  the user's own trimester), list of published exercises, a real empty state
  when none are published (hands off to Kegel).
- `app/(app)/herramientas/ejercicios/[id]/page.tsx`: static per published
  exercise (`generateStaticParams`), 404s for anything unpublished.
- `app/(app)/herramientas/page.tsx`: one tile, locked/"Pronto" exactly like
  the video gallery, `locked: PUBLISHED_EJERCICIOS.length === 0`. Reused the
  existing (currently unused) `"checklist"` icon rather than touching
  `ToolIcon.tsx`, which is outside this unit's Owns block.
- `lib/server/contentDebt.ts`: one row ("Ejercicios", `/herramientas/ejercicios`,
  gates: placeholder).
- `public/assets/ejercicios/README.md`: the 24 exact filenames (12 exercises
  × 2 steps) the founder drops in, one exercise at a time — publishing does
  not require all 24 at once, and needs no code change, only the JSON edit
  pointing `imageSrc` at the real file.
- `e2e/ejercicios.spec.ts`, `lib/seed/ejercicios.test.ts`.

## Decisions
- **No week-precision "no supine after 16" test is possible** — this app
  only tags exercises by trimester (1/2/3), and trimester 2 spans both sides
  of week 16. Resolved by never authoring a supine (boca arriba) exercise at
  all — side-lying instead — which satisfies the rule for every trimester.
  The test asserts no entry, at any trimester, mentions a supine position.
- **The "e2e: with one entry given a real test image" ask is not built as a
  Playwright spec.** Doing so for real would require committing a real image
  and a non-placeholder `imageSrc`, which permanently unlocks the tile in
  production — directly contradicting this unit's own exit criterion ("the
  tile is locked in production today"). `e2e/precios.spec.ts` sets the same
  precedent for a gated collection: it only tests the shipped empty state.
  The "lights up once a real file lands" behaviour is instead proven at the
  unit level, against a synthetic fixture that never ships
  (`lib/seed/ejercicios.test.ts`, "the gate itself, proven against a
  synthetic fixture").
- Weight-gain-band-style clinical content stays out entirely — every entry
  is general wellness (walking, stretching, posture), nothing that reads as
  an instruction for a diagnosed condition, per PR-19's line.
- Kegel is represented in the list (for discoverability under "Ejercicios")
  but its steps hand off to the existing dedicated tool rather than
  duplicating the timer.

## Known issues
- All 12 exercises are unpublished until the founder supplies real step
  images per the README; the tile stays "Pronto" until then.
- `ToolIcon.tsx` was not touched — the tile reuses the existing unused
  `"checklist"` icon, which is a thematic mismatch. A dedicated exercise
  icon is a one-line addition for whichever unit next touches that file.
