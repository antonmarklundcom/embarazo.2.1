# W2 — docs entrance + scripts typecheck

Spec: `prompts/sonnet-w2-docs-index.md`. Branch: `unit/w2`.

## What changed

- **`docs/INDEX.md`** (new) — the single entrance to `docs/`: a 6-line "start
  here" list, then one table covering every file under `docs/` (current /
  history, read-when, superseded-by), plus a small table for the root-level
  docs (`README.md`, `DECISIONS.md`, `AGENTS.md`). `docs/PLAN-2026-09-13-GO-LIVE.md`
  is listed as the current build queue, per the dispatch.
- **`docs/archive/`** (new) — six superseded plans moved with `git mv`, content
  and banners untouched: `OPUS-REVIEW-2026-08.md`, `FABLE-PLAN-2026-08.md`,
  `HANDOFF-2026-08-21.md`, `REDESIGN-PLAN.md`, `REVIEW-AND-LAUNCH-PLAN.md`,
  `MVP-AND-MONETISATION.md`. Grepped the repo first: no test or script reads
  any of these six by path (only `lib/i18n/guaraniReview.test.ts` reads a
  docs file directly, `docs/GUARANI-REVIEW.md`, which does not move), and no
  markdown file anywhere uses an actual `](path)` link to any of them — only
  inline-code prose mentions — so no stub/pointer files were needed at the
  old paths.
- **`README.md`** — one pointer line added under the title, to `docs/INDEX.md`.
- **`tsconfig.json`** — added `**/*.mts` to `include` so `scripts/*.mts` is
  typechecked.
- **`scripts/gen-guarani-review.mts`** — fixed the two `TS2339` errors that
  `**/*.mts` surfaced. Two of the five `CHEERS` (`lib/sharing/cheers.ts`) ship
  without a Guaraní line on purpose, so `gn` is absent from those entries'
  literal type, not merely falsy; `.filter((c) => c.text.gn)` does not narrow
  the mapped type. Added a `hasGuarani<T>` type guard (`item is T & { text:
  { gn: string } }`) and used it in the `CHEERS.filter(...)` call instead of
  a cast, per the spec.

## Verification

- `npx tsc --noEmit` clean, now covering `scripts/*.mts`.
- `npm run gen:guarani-review` regenerates `docs/GUARANI-REVIEW.md`
  byte-identical (`git diff` on that file is empty) — the drift test stays
  green.
- Every link in `docs/INDEX.md` resolves (checked against the filesystem).
- Every file under `docs/` appears in `docs/INDEX.md` exactly once — the 14
  top-level files individually, the 6 archived files individually, and
  `docs/log/*.md` as one row (a build-unit-log directory, not a plan).

No file's content changed except the four the spec names (`docs/INDEX.md`,
`README.md`, `tsconfig.json`, `scripts/gen-guarani-review.mts`) plus the
archive moves (content untouched) and this log.
