## 3. Business advice (summary)

- **Stop building, start distributing.** ~64k lines of TS, 1,440 unit tests,
  ~8k lines of process docs, zero users. Freeze features for 30 days.
- **Market size:** ~140k births/yr → ~105k pregnant at any time; the
  sponsor-relevant private-pay segment is ~25–35%. Realistic year-1: 5–15k
  installs, 2–6k monthly actives, **US$5–25k revenue**. It grows beyond that
  only via B2B or neighbouring countries.
- **Revenue, most likely first:** (1) clinic/ecografía/sanatorio/farmacia
  category sponsorships, ₲1–3M/month each, sold as presence + exclusivity,
  not CPC; (2) user-initiated WhatsApp lead-gen (never pass user data);
  (3) brand sampling box (exclude formula — breast-milk-substitute
  marketing rules); (4) B2B co-branded app for prepagas/sanatorios/employers
  (slow, highest value — start conversations now). Skip premium/AdMob for now.
- **Acquisition:** obstetra & ecografía waiting-room QR cards with per-clinic
  `?src=`; WhatsApp share cards; mothers' Facebook groups + your own
  moderated WhatsApp group; TikTok/Reels "Semana X" series; SEO pilot pages
  on embarazo.com.py (due-date calculator, maternity-leave rights).
- **Measure from day 1:** activation (onboarding done + 1 tool used) ≥ 60%,
  W1 ≥ 35%, W4 ≥ 20%, invites accepted per active owner ≥ 0.3, CAC per channel.
- **Risks:** un-reviewed legal texts on health data; single volunteer medical
  reviewer (pay a small retainer, recruit two); keep "Ask Flo"-style AI parked.

## 4. Can Opus do better?

The prior build process produced unusually careful code (server-side authz
everywhere, atomic LWW sync, hashed single-use tokens, frozen Dexie migration
lists, a test that fails if admin code reads health payloads). This review
still found real bugs it missed — the pre-hijack/admin pair, the revoked
invite, the labour WhatsApp fallback, a hydration bug that showed broken
images on every week page — mostly **cross-feature** issues where two
individually-correct units combine badly (PR-20 password sign-in × the older
"email linking is safe" decision). The lesson: add a periodic whole-system
review pass, not just per-unit review. More process docs are not the gap.
